# 🌙 Eid ul Adha Mubarak — Animated Web Greeting Card

A beautifully designed, fluid, and fully responsive animated web greeting card to celebrate Eid ul Adha. This project features custom glassmorphism UI elements, an adorable animated floating sheep mascot, custom interactive slides, and ambient particle effects.

✨ **[Live Demo: See it in action here!](https://jamiha07.github.io/Eid_Greeting/)** ✨

---

## 📸 Preview & Design Vibe
The interface features a deep, elegant maroon gradient canvas embellished with glistening gold borders, a shimmering starlight canopy, dynamic floaters, and smooth slide transitions built entirely from scratch.

* **Slide 1:** An inviting animated intro featuring a cute sheep wearing a flower crown that dynamically bobs up and down. Includes an interactive "Blessings Button".
* **Slide 2:** A dedicated festive celebration page hosting a curated snapshot and your personalized greeting.
* **Slide 3:** A cinematic reveal featuring striking Arabic typography and a stunning, interactive hovering "Wish Card" embedded with traditional celestial design details.

---

## 🛠️ Built With

This project is built purely with clean vanilla web technologies, requiring no bulky frameworks or heavy compile steps:

* **HTML5:** Semantic structure for optimal accessibility and layout.
* **CSS3:** Advanced responsive typography using `clamp()`, smooth custom `@keyframes` animations, and glassmorphic card layouts (`backdrop-filter`).
* **JavaScript (Vanilla):** Dynamic, light-weight slide-switching architecture, curtain reveal sequences, and state management.
* **Google Fonts:** Embedded `Cinzel`, `Cormorant Garamond`, `Amiri`, and `Nunito` typographies.
